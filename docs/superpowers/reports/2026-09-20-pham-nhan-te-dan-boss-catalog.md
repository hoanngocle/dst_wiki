# Phàm Nhân Tu Tiên 2.0 trial boss catalog audit

Audit date: 2026-09-20. This is a source audit, not a play-test. Native evidence is from `data/databundles/scripts.zip`; paths below use `scripts.zip!/scripts/...`. Historical Solo Leveling provenance is from `mods/mod_steam/3780347550`; that content is now integrated into Phàm Nhân rather than supplied as an optional Workshop dependency.

## Result

The safe catalog is **one entry per encounter/family or authored encounter variant**, not one entry per prefab carrying `epic`. I found 37 native Survival encounter records that can be supported when the historically Solo-recognized lower tier and current rift variants are included. Some require scoped activation/completion adapters, two Forge-only bosses are not safe on an ordinary Survival shard, and the integrated subsystem adds six direct boss prefabs plus seven registered “super treasure” encounter variants. Together with the retained authored Shadow Thrall encounter, the runtime catalog has exactly 51 records.

Exact catalog IDs by source are:

- Native (37): `minotaur`, `antlion`, `bearger`, `mutatedbearger`, `beequeen`, `celestial_champion`, `alterguardian_phase1_lunarrift`, `alterguardian_phase4_lunarrift`, `crabking`, `deerclops`, `mutateddeerclops`, `dragonfly`, `eyeofterror`, `twins_of_terror`, `klaus`, `lordfruitfly`, `malbatross`, `moose`, `daywalker`, `daywalker2`, `shadow_chess`, `sharkboi`, `spiderqueen`, `toadstool`, `toadstool_dark`, `stalker`, `stalker_atrium`, `leif`, `leif_sparse`, `fruitdragon`, `warg`, `claywarg`, `gingerbreadwarg`, `mutatedwarg`, `wagboss_robot`, `worm_boss`, `vault_pillar_guard`.
- Retained authored encounter (1): `shadow_thralls`.
- Integrated Solo-derived direct encounters (6): `solo_minotau`, `solo_hh_sharkboi`, `solo_hh_beetle_pig`, `solo_hh_dual_wield_pig`, `solo_hh_igris_dungeon`, `solo_hh_beru_dungeon`.
- Integrated treasure variants (7): `solo_mutateddeerclops_boss`, `solo_mutatedbearger_boss`, `solo_mutatedwarg_boss`, `solo_hh_sharkboi_boss`, `solo_walrus_adc`, `solo_treasure_kps`, `solo_treasure_cat_you`.

The native `epic` scan was exhaustive over the installed archive. Literal `AddTag("epic")` occurs in: `malbatross`, `worm_boss`, `stalker`, `beequeen`, `lavaarena_boarrior`, `toadstool`, `warg` (mutated form only), `spiderqueen`, `sharkboi_water`, `minotaur`, `klaus`, `leif`, `shadowchesspieces`, `lavaarena_beetletaur`, `alterguardian_phase3`, `fruitfly` (Lord only), `alterguardian_phase4_lunarrift`, `deerclops`, `daywalker`, `crabking`, `eyeofterror`, `antlion`, `moose`, `dragonfly`, `daywalker2`, `vault_pillar_guard`, `wagboss_robot`, `alterguardian_phase1`, `bearger`, `sharkboi`, and `alterguardian_phase2`. This is a candidate inventory: phase prefabs, proxies, and event prefabs still need the family decisions below.

## Pool/adapter acceptance checklist

1. Build the pool from encounter records, then filter integrated Solo-derived records by subsystem capability and prefab existence. Missing prefabs must not be passed to `SpawnPrefab`.
2. Use one completion counter per encounter: both Twins, all three Shadow Pieces, and the full Champion phase chain must finish before reward. Internal minions/proxies never increment the boss count.
3. Add explicit activation hooks for Antlion, Crab King, Twins, Wagboss Robot and Fuelweaver; direct `SpawnPrefab` alone does not recreate their intended fight.
