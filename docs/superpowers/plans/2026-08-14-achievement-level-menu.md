# Achievement & Level Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an `Achievement & Level` navigation item and a searchable three-tab `/achievement-level` reference page backed by the complete decoded data from Workshop mod `2937640068`.

**Architecture:** Commit the decoded Markdown audit and convert its tables into a deterministic JSON artifact. A pure TypeScript module validates and filters that artifact, a synchronous App Router Server Component renders metadata/summary content, and one narrowly scoped Client Component owns tabs and filters.

**Tech Stack:** Python 3 standard library, JSON, TypeScript 5, Next.js 16.2 App Router, React 19.2, Radix Tabs, Tailwind CSS 4, Vitest 4, React Testing Library.

## Global Constraints

- The public navigation label is exactly `Achievement & Level`, immediately after `Cảnh giới Tu Tiên`.
- The route is exactly `/achievement-level`; `Nhiệm vụ` is the default tab.
- Publish exactly 763 task occurrences in 28 pools, 169 achievements, 128 purchasable perks, and 18 character task groups.
- Preserve each task occurrence by pool/index; do not deduplicate repeated actions across seasons or characters.
- Preserve the Vietnamese locale strings exactly as supplied by the mod, including English strings that remain in `main_strings_vi.lua`.
- Production runtime must not read Steam, the Workshop directory, Lua, or Markdown.
- The source snapshot is Workshop ID `2937640068`, mod version `7.3.4`.
- No pagination: unfiltered tabs expose all records; use CSS content visibility for long lists.
- Keep the existing light `nova-*` visual tokens and shared DST shell/components.
- Do not modify unrelated item, character, cultivation, or design-system behavior.

```python
from __future__ import annotations

import argparse
import json
import re
import unicodedata
from pathlib import Path
from typing import Any


JsonObject = dict[str, Any]


def _slug(value: str) -> str:
    normalized = unicodedata.normalize("NFKD", value)
    ascii_value = "".join(char for char in normalized if not unicodedata.combining(char))
    return re.sub(r"[^a-z0-9]+", "-", ascii_value.lower()).strip("-")


def _cells(line: str) -> list[str]:
    return [cell.strip().replace("\\|", "|") for cell in line.strip().strip("|").split("|")]


def _table_after(lines: list[str], heading_index: int) -> list[list[str]]:
    cursor = heading_index + 1
    while cursor < len(lines) and not lines[cursor].startswith("|"):
        cursor += 1
    if cursor + 1 >= len(lines):
        raise ValueError(f"table missing after {lines[heading_index]}")
    cursor += 2
    rows: list[list[str]] = []
    while cursor < len(lines) and lines[cursor].startswith("|"):
        rows.append(_cells(lines[cursor]))
        cursor += 1
    return rows


def _plain(value: str) -> str:
    return value.replace("`", "").strip()
```

def build_artifact(report_path: Path, output_path: Path) -> JsonObject:
    artifact = parse_report(report_path.read_text(encoding="utf-8"))
    output_path.parent.mkdir(parents=True, exist_ok=True)
    output_path.write_text(
        json.dumps(artifact, ensure_ascii=False, indent=2) + "\n",
        encoding="utf-8",
    )
    return artifact


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--report", type=Path, default=Path("mod-achievement-level-2937640068.md"))
    parser.add_argument("--output", type=Path, default=Path("data/manual/achievement-level.json"))
    args = parser.parse_args()
    build_artifact(args.report, args.output)


if __name__ == "__main__":
    main()
