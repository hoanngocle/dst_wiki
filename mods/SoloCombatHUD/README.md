# Solo Combat HUD

Hướng dẫn cài đặt, cấu hình và playtest bằng tiếng Việt nằm trong [README_VI.md](README_VI.md).

Install this folder on the DST server and every client. Disable the standalone Simple Health Bar DST and Epic Healthbar mods, keep Solo Leveling enabled, and set Solo's text effects option off. This mod restores EXP, quest, and level notifications selectively while replacing combat text with one server-resolved popup system.

Source attribution and known staging limits are documented in `README_VI.md`.
